# 电商用户行为漏斗与渠道增长分析
> 基于MySQL完成电商用户行为全流程数据分析，实现数据清洗、用户画像、转化漏斗、渠道质量评估、多维度交叉分群，定位业务流失瓶颈，输出可落地运营策略。

## 📌 项目简介
本项目使用10万条电商用户行为访问数据集，通过MySQL完成完整的数据分析闭环。
分析维度包含数据预处理清洗、用户结构画像、五级转化漏斗、渠道质量、设备系统、区域市场、新老用户、年龄性别分群、浏览深度、支付流失专项、多维度交叉分析，挖掘电商转化链路中的问题，输出业务洞察与运营优化建议。

**数据集规模：100000条用户行为样本**

## 🛠️ 技术栈
- 数据库：MySQL 8.0
- 客户端工具：DBeaver
- 输出产物：SQL分析脚本、Markdown完整分析报告
- 可选可视化：Power BI（漏斗图、占比饼图）

## 📊 核心业务指标摘要
1. **整体转化**：整体订单确认转化率仅 **2.40%**
2. **漏斗瓶颈**：最大流失节点为**商品页→支付页，流失率86.17%**；其次支付页到确认页流失64.97%
3. **渠道表现**
    - Direct自然流量：转化率3.03%，渠道质量最优
    - Ads广告流量：转化率1.65%
    - Seo搜索流量：转化率1.55%
4. **用户结构**
    - 用户：老用户占比68.48%，新用户占比31.53%
    - 性别：女性占60.55%，转化率3.02%；男性占38.67%，转化率仅1.45%
    - 年龄主力：20‑29岁(41.67%)、30‑39岁(37.23%)；20岁以下转化率最高4.13%，50岁及以上无转化
5. **设备系统**
    - Mac桌面设备转化率最高3.83%；Linux、other设备转化表现较差
6. **浏览深度相关性**
    - 浏览10页以上用户确认转化率达到**16.74%**，远高于整体水平；浏览≤3页几乎不会产生下单
7. **区域市场映射**
    - market_clean：1=华东，2=华南，3=华北，4=西南；西南市场整体转化率3.20%表现最优

## 🔍 关键业务发现
1. 转化最大痛点在**商品跳转支付环节**，大量用户进入支付页后放弃下单，是首要优化点。
2. Direct自然流量质量远高于广告、SEO引流；Ads、Seo带来大量访客，但下单意愿弱，存在无效流量。
3. 老用户转化率2.83%显著高于新用户1.47%，老用户商业价值更高；新用户虽然访问页数更高，但是下单意愿不足。
4. 女性用户转化明显优于男性；年轻群体（20岁以下、20‑29岁）是核心高转化客群；中老年群体到达支付页后流失极其严重。
5. 用户浏览深度与下单高度正相关，浏览页数越多，下单概率越高。
6. 西南、华南市场转化表现优于华东、华北市场。

## 💡 运营优化建议
1. **优先修复支付链路瓶颈**
    重点排查商品页跳转支付页流程，简化支付步骤，增加优惠弹窗、免密支付，降低支付页流失；针对中老年用户简化操作界面。

2. **渠道精细化运营**
    - 维护Direct自然流量，做好私域、收藏回访，提升老用户复购；
    - Ads、Seo渠道需要优化投放人群定向，过滤低质量访客，减少只浏览不下单的无效流量；不同区域渠道效果差异大，可以做区域差异化投放策略。

3. **用户分层运营**
    - 高价值群体：女性、20‑29岁年轻用户、Mac/iOS桌面端、西南华南市场，可针对性推送活动、商品推荐；
    - 新用户：新用户访问深度尚可，但转化低，设计新客专享券，引导完成首次下单；
    - 男性、中老年群体：优化商品推荐与支付体验，降低操作门槛。

4. **提升用户浏览深度**
    完善商品关联推荐、专题活动、种草内容，引导用户多浏览商品，提升访问页数，从而提高下单转化概率。
