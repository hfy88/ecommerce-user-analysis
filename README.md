# 电子商务用户行为分析项目
> 项目：基于MySQL电商用户行为数据集，完成数据清洗、漏斗转化、用户分群、多维度交叉分析，输出业务结论，可用于CDA实训、数据分析求职项目。

## 一、项目简介
### 1. 项目背景
电商平台存在用户下单流失严重的问题，本次通过用户访问行为数据，搭建转化漏斗，定位流失节点，从渠道、设备、地区、年龄性别、新老用户维度拆解转化差异，找到高价值用户群体与优化方向，给运营、产品提供策略建议。
### 2. 数据说明
- 原始表：`淘宝用户行为` / `用户行为漏斗与渠道增长`
- 清洗后表：`user_behavior_clean`
- 字段清单：
  | 字段 | 含义 |
  | ---- | ---- |
  | new_user | 是否新用户（1=新用户，0=老用户） |
  | age | 用户年龄 |
  | sex | 用户性别 |
  | market | 地区编码 |
  | device | 设备类型 |
  | operative_system | 操作系统 |
  | source | 流量渠道 |
  | total_pages_visited | 总访问页面数 |
  | home_page | 首页访问标记 |
  | listing_page | 列表页访问标记 |
  | product_page | 商品页访问标记 |
  | payment_page | 支付页访问标记 |
  | confirmation_page | 确认下单页标记 |

### 3. 工具栈
MySQL（DBeaver）+ SQL 数据分析，可拓展PowerBI可视化

## 二、分析流程（完整链路）
1. 数据探查：缺失值、重复值、异常值校验
2. 数据清洗：CASE映射、异常值置空、生成清洗表 `user_behavior_clean`
3. 用户画像：新老用户、性别、年龄、地区分布
4. 核心漏斗：五级转化漏斗 + 各环节流失率计算
5. 单维度拆解：渠道、设备、操作系统、地区、新老用户、年龄性别转化对比
6. 浏览深度分析：访问页数和转化率关系
7. 专项流失分析：支付页流失人群拆解
8. 多维度交叉分析：渠道×设备、渠道×新老用户、地区×渠道、年龄×性别等
9. 结论输出 + 业务建议

## 三、SQL文件说明
> 全部SQL在DBeaver中执行，先执行清洗脚本，再依次执行各个分析模块
1. `01_data_check_and_clean.sql`：缺失、重复、异常探查 + 生成清洗表
2. `02_user_profile.sql`：用户结构画像统计
3. `03_funnel_analysis.sql`：转化漏斗、流失率
4. `04_dim_analysis.sql`：渠道/设备/地区/新老用户/年龄性别单维度分析
5. `05_payment_churn.sql`：支付页流失专项
6. `06_cross_analysis.sql`：多维度交叉转化分析

## 四、核心指标解释
- 到达率：进入该页面用户 / 总用户
- 环节转化率：进入下一页面用户 / 当前页面用户
- 整体确认转化率：最终下单确认用户 / 全部用户
- 流失率：当前页面未进入下一环节用户 / 当前页面用户

## 五、核心业务结论（答辩直接用）
1. 整体漏斗：整体确认转化率仅2.40%，**最大流失节点：商品页→支付页（流失率86.17%）**，是首要优化点；其次支付页流失严重（64.97%）
2. 渠道质量：Direct（直接访问）转化率最高(3.03%)，Seo、Ads流量转化偏弱；Seo渠道支付页流失最高
3. 设备&系统：Mac桌面端转化最好；移动端流量大，但转化低于桌面端
4. 用户分层：老用户转化率2.83%显著高于新用户1.47%；20岁以下、20-29岁年轻群体转化能力更强；女性转化优于男性
5. 地区：西南地区转化最优，华北转化最差
6. 浏览深度强相关：浏览页数越高，转化率陡增，10页以上用户转化率高达16.74%

## 六、优化建议
1. 商品→支付环节：优化结算页、简化下单流程，减少表单、增加支付方式
2. 渠道投放：优先加大Direct渠道维护；对Seo、Ads落地页做优化，降低支付页流失
3. 用户运营：重点维护20-29岁女性用户；针对新用户做首单优惠，提升新客转化
4. 地区运营：参考西南地区运营策略复制到其他区域；华北地区针对性调研流失原因
5. 引导用户多浏览：商品页做关联推荐，提升用户浏览深度，拉动转化

## 七、项目复盘&面试话术
- 难点：多维度交叉转化、窗口函数计算占比、漏斗的正确口径（顺序访问判断）
- 知识点：GROUP BY分组聚合、窗口函数`OVER()`、CTE表达式、CASE WHEN分箱、COALESCE空值处理、NULLIF防除零报错
- 拓展方向：可以导入PowerBI绘制漏斗图、渠道转化看板，或者用Python做用户分群RFM
